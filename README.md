# 发芽口径核算台

种子检验室按书面口径给批次出数。现行口径的分母是播种粒数减去霉粒数，分子是发芽粒数。旧口径把霉粒留在分母里。核算员可以按现行口径再出一版，旧版数字仍留在记录里。

某一床的发芽粒加霉粒超过播种数时，这一批成为超限批。超限批不能直接出数：先钉剔床口径，再按口径修订入账。

## 剔床口径

| 算法 | 修订结果 | 超限粒 |
|------|----------|--------|
| 整批不出数 | 整批挡下，作废，不出版发芽率 | 不进任何分母 |
| 剔除超限床 | 整床丢掉，其余床按现行口径入账 | 不进分母 |

- 口径按批次、按日钉死，本日之内不能再改；第二天才能另钉。
- 剔床盘未钉死之前，修订超限批一律拒绝。
- 修订报文里的剔床算法必须与剔床设置一致，否则记「剔床跑偏」，超限批拒入账。
- 白班与夜班检验员同时修订同一超限批时互斥写入，只放行与剔床设置相符的结果，慢一步的记「剔床争用」。
- 播种粒空白的床不进过限队列，也不参与分母。

## 界面

- 超限列表：挡下回数、丢掉回数、口径名，以及每张超限床的超限粒。
- 原床详情：每床并排原床发芽率与修订后发芽率，并注明入账 / 挡下 / 空白。
- 修订条目：整批挡下与剔除超限床分成两张卡片，只有与剔床设置相符的一张可以提交。
- 争用与跑偏记录：剔床跑偏、剔床争用、未钉死即修订的尝试都留痕。
